# 音频资源说明

游戏内置三首文件曲目（OGG 格式），因**版权原因不入库**，请自行获取后按以下文件名放入本目录：

| 文件名 | 用途 |
| --- | --- |
| `SPECIALZ.ogg` | 主题曲 / 主界面 |
| `aizo.ogg` | 对战曲 |
| `yuai.ogg` | 专属曲（仅"觉醒五条悟 vs 受肉伏黑惠宿傩"对决播放） |

## 缺失时会怎样？

不会怎样——游戏内置了 **Web Audio 实时合成的芯片音轨**作为回退。任一音频文件缺失时，自动切换到对应合成曲目，游戏功能完全不受影响。放入音频文件并刷新页面即可无缝替换为原曲。

## 技术实现

见 `public/js/audio.js`：曲目经 `fetch` 加载并解码为 `AudioBuffer`，以 `BufferSource` 无缝循环播放；加载失败时回退（`fallback`）到对应合成音轨。
